# PhishNet — Typed Logical ERD Notes

The [3NF-labeled ERD](erd-3nf.mmd) is a concise **presentation view** of the core product. The name reflects the requested progressive drawing convention (concepts → keys → datatypes) rather than claiming that the 14 entities have passed formal 3NF analysis.

The typed view depicts the core interaction, claim, evidence, financial mandate, independent approval, deterministic decision, and execution records. An implementation must follow [schema-implementation-checklist.md](schema-implementation-checklist.md) to add durable authorization and audit tables without cluttering the introductory chart.

Do not derive a production SQL schema from the diagram alone. Review [requirements.md](requirements.md), [testing.md](testing.md), and [research-context.md](research-context.md) first.
