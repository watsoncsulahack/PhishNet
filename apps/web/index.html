    Settings

    Local tools. Explicit permissions.

    Wallet journal

    Connect your wallet to sign in. Signing a login challenge does not approve a payment.

    Local agent

    Bring your own agent. Its wallet-scoped capability permits typed reads and unsigned payment proposals. It cannot approve or sign.

    Copy once into your separately managed local agent. Keep this credential private.

    Use node scripts/agent-tool.mjs jobs with PHISHNET_AGENT_TOKEN in the local process environment. See connector setup.

    Human authorization

    Loading public enrollment profile…

    Agent payments require a separately controlled CounterSign keyed credential, then external wallet approval. This app does not attest hardware or host isolation.

    Audit checkpoints

    Only event hashes and sequence metadata can be committed to Arc. Encrypted chat and source content remain off-chain. Unanchored records are local observations.

    Install PhishNet

    Install from your browser menu over HTTPS or localhost. The public shell works offline; sending and verification require a network connection.

    Voice input is not implemented. Your wallet works without a local model.
