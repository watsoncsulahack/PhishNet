    YOUR WORKSPACE

    Settings

    Local tools. Explicit permissions.

    Wallet journal

    Connect your wallet to sign in. Signing a login challenge does not approve a payment.

    Local agent

    Send prompts straight from Wallet or Chat over automatic local SSE/MCP — no terminal token setup required. Agents have read & draft proposal access only; they cannot approve or sign transfers.

    Advanced: External CLI / MCP endpoint

    Optional for connecting an external desktop IDE, MCP client (SSE/HTTP at /v1/mcp), or terminal bridge (`npm run agent:bridge`). Built-in Antigravity and Codex chat backends work automatically without creating or pasting tokens.

    Copy once into your separately managed external agent or MCP Bearer header. Keep this credential private.

    MCP endpoint: /v1/mcp (SSE + Streamable HTTP JSON-RPC) or CLI bridge: npm run agent:bridge. See connector setup.
    Human authorization
    Loading public enrollment profile…
    Every transfer ALWAYS requires your external wallet (MetaMask) signature. CounterSign is an optional second independent human Ed25519 signature (separate from your agent and wallet) you can enable if you want two-key co-signing before MetaMask opens.
    Audit checkpoints
    Only event hashes and sequence metadata can be committed to Arc. Encrypted chat and source content remain off-chain. Unanchored records are local observations.
    Browser app & offline shell
    Optional: save PhishNet to your home screen or desktop app launcher from your browser menu (Install / Add to Dock). The cached public UI loads offline, while wallet connections, journal decryption, and receipt verification require a network connection.
    Voice input is not implemented. Your wallet works cleanly without an AI backend.
